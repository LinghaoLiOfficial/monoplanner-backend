# 数据集与同步一致性指标优化

## 实际开发集诊断

开发集包含 2 条需求链、6 个连续变更、18 个提示包和 219 个事实审阅项。
实际盲审显示：158 项一致、35 项漏项、25 项无法判定、1 项共同错误，没有观察到
有双端证据支持的矛盾。18 个计划包中，7 个可有效评价且均为 `C=0`；10 个因漏项
或无法判定而不可评价；1 个存在结构性端范围错误。

因此，单独报告 `C_total=0` 会产生误导。当前主要失败模式是提示包没有完整表达同步
契约，而不是已经表达的前后端指令直接冲突。

## 数据集 v2 设计

每个原子事实应从目前的 `fact_id + target + value` 扩展为：

```json
{
  "fact_id": "stable-semantic-id",
  "statement": "可直接判断真假的完整事实陈述",
  "target": "request.title.min_length",
  "value": 3,
  "operation": ["create", "update"],
  "state": "after-c01-s1",
  "category": "validation",
  "required_sides": ["frontend", "backend"],
  "coverage": "must_be_explicit",
  "supersedes": [],
  "sources": ["requirement:c01-s1"]
}
```

优化要求：

1. `required_sides` 下沉到每个事实，避免把后端存储规则误判为前端漏项，或把界面行为
   误判为后端漏项。
2. `statement` 必须包含操作、状态和条件，使审阅者无需从键名推断语义。
3. `coverage` 区分必须在提示中明确出现的事实与可以从其他明确事实推出的事实。
4. `state` 和 `supersedes` 表达链内继承、替换与回退，避免只评价当前句子而忽略已废止规则。
5. 将原始仓库事实、假设性新要求和保留约束分别标注来源类型。
6. 每条链保持独立；同一链的三个步骤不得跨开发集和测试集。
7. 为每类契约至少包含一次新增、修改和撤销/回退，并保留单端事实作为边界样本。

## 优化后的指标体系

主指标仍为每包矛盾数 `C`，但必须与以下门控指标共同报告：

| 指标 | 公式 | 用途 |
| --- | --- | --- |
| 结构有效率 | 结构有效包数 / 全部计划包数 | 防止空包、错端范围获得零分 |
| 可评价率 `E` | 无漏项且无无法判定的包数 / 全部计划包数 | 显示 `C` 的有效覆盖范围 |
| 矛盾总数 `C_total` | 可评价包中去重后的 contradiction 事实数 | 主同步矛盾量 |
| 平均矛盾数 `C_mean` | `C_total` / 可评价包数 | 仅在同时报告 `E` 时使用 |
| 严格成功率 `S` | 结构有效、可评价、`C=0` 且无共同错误的包数 / 全部计划包数 | 对应 90% 预登记目标 |
| 事实漏项率 | omission 事实数 / 已审阅事实总数 | 识别契约覆盖不足 |
| 事实不确定率 | uncertain 事实数 / 已审阅事实总数 | 识别数据或提示表述歧义 |
| 共同错误率 | common_error 事实数 / 已审阅事实总数 | 防止两端一致但共同错误被判成功 |

`C=0` 只表示已评价事实中没有双端直接矛盾，不等于成功。正式结论以严格成功率 `S`
为主，并同时展示 `E`、漏项率、不确定率和共同错误率。

## 实验汇总原则

- 按方法、需求链和重复次数分别汇总，不把链内步骤视为相互独立的统计样本。
- 规则基线的重复输出只计运行单位，不宣称为独立随机观测。
- 生成失败、结构无效和不可评价均保留在全部计划单位分母中。
- 方法比较采用同一需求步骤与同一重复编号的配对差异。
- 测试集冻结后不根据结果修改事实定义；修订进入新数据版本并保留旧结果。
- 完整编排层与直接提示包层单独报告，不能将两者单位合并为一个效果指标。

## v2 小范围结果

已在两条开发链的 6 个步骤上运行 `rule` 与 `joint`，共 12 个单位：

- 12/12 生成完成，结构有效率 100%。
- 必须显式事实端数 164，覆盖 162，自动覆盖率 98.78%。
- 规则基线覆盖 82/82；联合生成覆盖 80/82（97.56%）。
- 联合生成唯一缺口出现在 `c01-s3` 的 `update-omitted-title-revalidate`。
- 实际模型调用 6 次，21,872 tokens，提供方报告成本 0.03615425。

盲审后的总体显式语义覆盖率为 92.68%，严格成功率为 91.67%，`C_evaluable=0`、
`C_observed=0`。规则基线覆盖率和严格成功率均为 100%；联合生成分别为 85.37% 和
83.33%。联合提示存在“输出事实 ID 但不展开具体值”的问题，因此联合方法尚未通过
90% 门槛。完整结果见 `results/v2-dev-pilot-20261003/`。

针对该缺陷的 v2.1 提示已在相同 12 单位上重跑并完成 82 项独立审阅：81 项一致、
1 项不确定，无漏项、矛盾或共同错误。总体显式语义覆盖率为 98.78%，规则基线为
100%，联合生成为 97.56%；总体严格成功率为 91.67%，规则基线为 100%，联合生成
为 83.33%。`C_evaluable=0`、`C_observed=0`，但不能忽略该不确定项。

v2.2 仅修正该不确定项暴露的可选实现建议风险，并完成 12 单位自动回归：生成完成率、
结构有效率、事实标记覆盖率和完整 statement 覆盖率均为 100%。相同 82 个事实已经
完成 v2 和 v2.1 两轮审阅，不再进行第三轮重复填写。最终结论以 v2.1 人工语义结果和
v2.2 自动回归结果共同组成；v2.2 的语义矛盾数、可评价率和严格成功率保持未定义。
