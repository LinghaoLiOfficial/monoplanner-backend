# 数据集 v2 与指标设计小范围测试最终汇总

## 结论

v2 数据设计成功修复了 v1 的主要测量缺陷：继承且可推导的契约事实不再因为未逐字
重复而被判为漏项；事实适用端和必须显式覆盖范围均在事实级定义。

12 个提示包全部生成成功，结构有效率 100%。盲审覆盖 82 个必须显式事实，得到 76 项
一致、6 项漏项，无矛盾、无不确定、无共同错误。

## 最终指标

| 指标 | 总体 | 规则基线 | 联合生成 |
| --- | ---: | ---: | ---: |
| 生成完成 | 12/12 | 6/6 | 6/6 |
| 可评价率 | 91.67% | 100% | 83.33% |
| 严格成功率 | 91.67% | 100% | 83.33% |
| `C_evaluable` | 0 | 0 | 0 |
| `C_observed` | 0 | 0 | 0 |
| 标记覆盖率 | 98.78% | 100% | 97.56% |
| 显式语义覆盖率 | 92.68% | 100% | 85.37% |
| 漏项率 | 7.32% | 0% | 14.63% |

6 个配对步骤中，规则基线严格胜出 1 个，其余 5 个持平，联合生成没有严格胜出。

## 关键发现

联合生成在 `c02-s1` 中输出了事实 ID 标记，却没有展开 6 个事实的实际契约值，包括
skip 下限/默认值、limit 上下限/默认值和非法请求状态码。这些事实不能仅凭标记视为
已覆盖。

因此指标必须永久区分：

- `marker_coverage_rate`：只检查 `[FACT:id]` 是否存在，用于结构追踪。
- `explicit_semantic_coverage_rate`：由盲审确认事实及其具体值是否明确表达。

后者才是正式质量指标。

## 与 v1 的关系

v1 开发集存在 35 个漏项和 25 个不确定项，只有 7/18 包可评价。v2 小测的不可评价包
下降为 1/12，且不确定项降为 0。这支持“v1 的低可评价率部分来自数据和评分设计”这一
判断，但不能把两轮分数差异全部归因于系统改进，因为 v2 同时改变了事实范围、输入
协议和提示格式。

## 下一步边界

当前不应直接扩展到 8 条测试链。先将联合提示修改为：每个 `[FACT:id]` 后必须原样包含
对应 statement 和具体 target value；随后重复同一 12 单位小测。只有联合生成自身的
显式语义覆盖率和严格成功率均达到至少 90%，才冻结 v2 并扩展测试集。
